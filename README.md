This is a pipeline for the calculation and analysis of the complexity of 3D cranial sutures in a mammal dataset. The pipeline is divided in three subsections, which are to be run in this order:

1>the "mesh_processing" steps are for creating, cleaning, and preparing meshes for the extraction of complexity metrics

2>the "data_extraction" steps are for calculating the various complexity metrics for each mesh, and assessing the validity of mesh processing steps

3>the "data_analysis" steps are for assessing the relationships among complexity metrics for each suture, estimating the best models explaining suture complexity and their effects, and validating model design
