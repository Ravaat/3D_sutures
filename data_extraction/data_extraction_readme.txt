Data extraction stage - calculating complexity metrics and validation checks for the mesh processing steps

alpha_complexity.py: this script is used to calculate the alpha complexity of meshes. Requires the cleaned and rescaled output meshes from the mesh processing steps, and the .csv file including the volume and centroid size of meshes (mesh_rescaled_volume_centroid_2.csv)

curated_script_complexity.Rmd: with the exception of alpha complexity, the four remaining complexity metrics are calculated using the 'habtools' package in R. Requires the cleaned and rescaled output meshes from the mesh processing steps. The second part of the script includes a check to assess the bias introduced by the processing steps. After calculating the fractal dimensions (FD) and rugosity of the original dataset ("complete_recast_metrics_2.csv"), one does the same for the same mesh datast where cleaning and remeshing have not been applied ("complexity_metrics_new.csv"). The bias is assessed by regressing the extracted complexity values for both datasets against each other and extracting various correlation statistics.
